# Folder untuk Upload Video Tutorial MP4

Unggah file video tutorial Anda ke folder ini dengan nama **`tutorial.mp4`** (sehingga jalurnya menjadi `/assets/mp4/tutorial.mp4` saat disajikan oleh server).

Aplikasi Komindo Billing System akan secara otomatis mendeteksi kehadiran file ini dan menampilkan pemutar video HTML5 lokal beresolusi tinggi sehingga pelanggan Anda dapat menonton panduan secara langsung dari server lokal Anda tanpa menggunakan kuota YouTube, sementara tombol opsi untuk membuka YouTube tetap tersedia.
